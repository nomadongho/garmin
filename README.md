# Garmin Watch Face

Custom Connect IQ watch faces for Garmin devices.

Initial target: **Forerunner 55** (208×208 round MIP display, 8 colours, Connect IQ 3.4).

Development is based on **Monkey C** and the **Garmin Connect IQ SDK**. Work is developed on feature branches and reviewed before merging into `master`.

The initial watch-face implementation and setup documentation will be introduced in a separate development branch.
